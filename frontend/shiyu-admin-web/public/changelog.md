# 更新日志

## v0.0.3

- 在线用户支持登录地点、操作系统和浏览器详细版本。
- 缓存监控支持查看 key 数据和删除 key。
- 数据监控切换进入时需要重新登录。
- 个人中心头像改为保存图片 URL 或站内路径，避免 base64 图片写入数据库。
- 用户管理列表优化用户编码列，支持单行省略和复制。
- 首页更新日志改为从独立 Markdown 文件维护，并按版本号展示。
- 在线用户会话改为按会话编号管理，强退后当前会话请求会被拦截。

## v0.0.2

- 个人中心支持资料展示、头像路径修改和密码修改。
- 系统监控提升为一级菜单，包含在线用户、服务监控、缓存监控和数据监控。
- 在线用户支持查看详情、强退、会话编号、部门名称、主机 IP、登录时间和最后访问时间。
- 用户新增头像字段，默认头像为 /logo-v2.png。
- 右上角用户菜单新增个人中心和修改密码入口。

## v0.0.1

- 首页内容完善：新增项目介绍、技术选型、联系信息和更新日志区域。
- 欢迎页菜单名称调整为首页。

## v0.0.0

- 更多群聊入口待补充。
- 项目路线图、文档链接和版本说明持续完善。
