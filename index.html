Local Quick Start

3 条命令启动完整环境

本地只需要安装 Docker 和 Docker Compose，即可启动前端后台、后端接口、PostgreSQL 和 Redis。

git clone https://github.com/Rodert/ShiyuAdmin.git
cd ShiyuAdmin
docker compose up -d
