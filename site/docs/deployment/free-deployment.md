# 免费部署方案

仓库已有免费部署方案说明：

- `docs/free-deployment.md`
- `docs/render-deployment.md`
- `docs/fly-deployment.md`

## 选择建议

| 场景 | 推荐 |
| --- | --- |
| 只展示官网文档 | GitHub Pages |
| 后端轻量体验 | Render 或 Fly.io |
| 完整数据库和 Redis | 云服务器 + Docker Compose |
| 长期稳定运行 | 云服务器、托管数据库、对象存储和日志监控 |

云服务器优惠入口见：[云服务器优惠](../resources/cloud-offers.md)。
