# 前端开发

前端项目位于 `frontend/shiyu-admin-web`。

## 启动

```bash
cd frontend/shiyu-admin-web
npm install
npm run start:dev
```

## 技术栈

- React
- Umi Max
- Ant Design Pro
- TypeScript
- ECharts

## 开发关注点

- 登录态和 JWT 存储。
- 动态菜单与路由生成。
- 表格、表单、权限按钮等后台常见交互。
- 仪表盘图表和全屏展示。
