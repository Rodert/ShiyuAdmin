开源通用后台管理系统

Shiyu Admin 仕宇通用管理后台

基于 Go、Gin、Gorm、React、Ant Design Pro 和 RBAC 的前后端分离后台脚手架， 适合快速搭建管理端、学习权限模型或作为新业务系统起点。

查看 GitHub 本地启动
01

开箱即用

Docker Compose 一条命令启动前端、后端、PostgreSQL 和 Redis。

02

权限完整

内置用户、角色、菜单、部门、动态菜单和接口权限控制。

03

低耦合

项目介绍页独立在 site 目录，后台系统仍保留在 frontend 目录。

Local Quick Start

本地启动

克隆仓库后，在项目根目录执行 Docker Compose，即可启动完整开发环境。

git clone https://github.com/Rodert/ShiyuAdmin.git
cd ShiyuAdmin
docker compose up -d
