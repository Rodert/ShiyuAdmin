# 0.2.0

- 新增首次安装向导，初始化系统名称和管理员；使用服务器安装授权码防止远程抢占。
- 自动生成并持久化独立 JWT 密钥，停止创建公开默认账号。
- 账号禁用、删除、改密后旧令牌失效；退出登录记录持久化到数据库，SQLite 无 Redis 也可撤销会话。
- 用户写操作校验数据范围，私有文件按上传者隔离；组织与权限配置写操作仅超级管理员可执行。
- 应用数据目录持久化；文件搜索兼容 PostgreSQL、MySQL、SQLite 和 SQL Server。
- 新增数据库迁移记录、版本信息、升级与回退指引，以及发布前的自动检查。

升级注意：旧登录令牌全部失效。使用已知默认密码的 admin 账号需先修改密码；默认密码的普通 user 账号将停用。请部署前阅读升级指引。
